# Concord Nova

Свой Discord на своём сервере: текстовые каналы, голос, видео, демонстрация экрана, личные сообщения и звонки. Работает в браузере, как программа для Windows и как приложение для Android.

- **Чат:** Markdown, подсветка кода, ответы, треды, опросы, реакции, закрепы, закладки, упоминания, отложенные сообщения, голосовые сообщения, превью ссылок и видео, GIF, свои эмодзи, поиск (с «ё» = «е»).
- **GIF:** своя кнопка в поле ввода.
  - «Избранное» — звёздочка на любой гифке в чате или в поиске; список хранится на сервере и одинаков на всех устройствах. «Недавние» — то, что отправляли с этого устройства. Обе полки работают без всякой настройки.
  - Поиск, «Популярное» и категории — через [KLIPY](https://klipy.com) (Tenor закрыт с июня 2026). Нужен бесплатный ключ с [partner.klipy.com](https://partner.klipy.com): администратор вставляет его в приложении, «Настройки → Сервер Nova → Обзор → Поиск GIF», — перезапуск не нужен. Пока ключ в тестовом режиме, KLIPY отвечает на 100 запросов в час; полный доступ запрашивается там же. Если ключ был у старого Concord, обновление сервера само достаёт его из архива `/root/concord-backup-*.tar.gz`.
  - Приложение ищет и загружает гифки напрямую у KLIPY, как того требуют его правила: сервер Nova только выдаёт ключ вошедшим пользователям и ничего у себя не хранит.
  - Сообщение из одной ссылки на GIF показывается картинкой, без адреса.
- **Голос и видео** через LiveKit (SFU):
  - шумоподавление на выбор: DeepFilterNet3 (убирает клавиатуру, вентилятор, улицу), лёгкий RNNoise для телефонов, системное или без него — модель лежит в приложении, ничего не скачивается со сторонних серверов;
  - изменение голоса: бурундук, великан, робот, рация, эхо, пещера и другие — переключается прямо в звонке;
  - сведения о подключении с графиком задержки и потерь, демонстрация экрана со звуком и на весь экран;
  - саундпад: кнопка в звонке с готовыми звуками (горн, «ба-дум-тсс», овации, сирена…) и своими — аудиофайл до 30 секунд со значком-эмодзи или своей картинкой. Звук подмешивается в голосовую дорожку после шумоподавления, поэтому его слышат все, даже когда микрофон выключен; свои звуки хранятся на устройстве;
  - пустой звонок завершается сам: если минуту больше никого нет (никто не ответил или все вышли), приложение отключается, за 10 секунд предупредив и предложив остаться. В настройках голоса — везде, только в личных звонках или никогда;
  - серверные mute/deafen, перемещение участников, «заглушить для себя»;
  - звонки в ЛС: шесть мелодий на выбор или свой аудиофайл.
- **Сервера:** роли и права как в Discord (включая права на каналы), приглашения, баны, тайм-ауты, журнал аудита, шаблоны серверов.
- **Надёжность:**
  - после любого переподключения клиент получает полный снимок состояния и дозагружает пропущенные сообщения;
  - повторная отправка не создаёт дублей (nonce);
  - голосовое состояние сверяется с LiveKit каждые 30 секунд.
- **Android:** свои push-уведомления без Google (работают и при закрытом приложении), входящие звонки на весь экран с кнопками «Ответить»/«Отклонить», демонстрация экрана, «Поделиться → Concord Nova».
- **Windows:**
  - трей и автозапуск;
  - глобальные горячие клавиши (mute/deafen) и оверлей для игр;
  - выбор окна или экрана для трансляции вместе со звуком;
  - автообновление.
- **Оформление:**
  - 6 тем и своя тема из любого цвета палитры, акцентный цвет, три уровня эффектов, «аура» говорящего;
  - обои чата: анимированные (звёзды, сияние, волны, снег, дождь…) или своя картинка, GIF, видео;
  - профиль: украшения аватара (корона, ушки, нимб, пламя…), анимированный эффект карточки, градиент из двух цветов — всё это видят остальные.
- **Администрирование в приложении** («Настройки → Сервер Nova», видно только администраторам):
  - статистика: аккаунты, кто в сети и в голосе, сообщения, место под файлы и базу;
  - аккаунты: сброс пароля (временный пароль показывается один раз), отключение, права администратора;
  - любой сервер можно передать другому участнику — например, если владелец отключён;
  - название и режим регистрации меняются без перезапуска.
- **Обновления:** Windows-программа обновляется сама из релизов GitHub, Android-приложение предлагает скачать новую версию, открытая веб-вкладка — перезагрузиться после выкладки.
- **Ссылки-приглашения** открывают приложение: внутри приложения — сразу окно «Вступить», из браузера — кнопка «Открыть в приложении» (протокол `concord-nova://`) и ссылка на скачивание для тех, у кого его ещё нет (адреса задаются `DOWNLOAD_WINDOWS_URL` / `DOWNLOAD_ANDROID_URL`).

## Устройство

| Папка | Что внутри |
|---|---|
| `packages/shared` | Общие типы, схемы (zod), права, ULID, упоминания |
| `server` | Fastify + Socket.IO + Prisma/SQLite, LiveKit, файлы, push |
| `client` | React 19 + Vite + Tailwind 4. Он же Electron (`client/electron`) и Android (Capacitor, `client/android-extras`) |
| `deploy` | Установка и обновление сервера (`setup.sh`), выкладка с ПК (`push.mjs`) |

## Запуск для разработки

Нужен **Node.js 24**.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Команда поднимает сервер API на `:4000`, Vite и локальный LiveKit (при первом запуске скачивается сам). Данные хранятся в `data/`, настройки описаны в `.env.example`. Первый зарегистрированный пользователь становится администратором.

Проверки: `npm run typecheck`, `npm test` и сквозные тесты в настоящем браузере `npm run e2e` (Playwright; с `SCREENS=1` ещё и снимки всех экранов в `.e2e-screens/`).

## Сервер (VPS)

Подходит Ubuntu 22.04/24.04. Самый простой способ: дважды щёлкните **`deploy-server.cmd`** в папке проекта и введите пароль root, когда его спросят. То же самое из терминала:

```bash
node deploy/push.mjs root@138.16.224.172 --purge-old
```

Пароль спросят один раз. Скрипт упакует исходники, передаст их по SSH и запустит на сервере `deploy/setup.sh`. Тот сделает следующее:

1. Установит Node 24, nginx, certbot, LiveKit, настроит ufw (порт SSH остаётся открытым) и добавит swap, если памяти мало.
2. Соберёт новую версию рядом с работающей.
3. С `--purge-old` уберёт старый Concord, в таком порядке:
   1. остановит его;
   2. **заархивирует** в `/root/concord-backup-<дата>.tar.gz` (база, загрузки, `.env`, unit и сайт nginx) и проверит, что база попала в архив;
   3. **перенесёт в Nova** аккаунты, друзей, серверы, роли, каналы, ЛС, сообщения, файлы, эмодзи и приглашения;
   4. только после этого удалит `/opt/concord`, сервис `concord` и его сайт nginx.

   Если перенос не удался, ничего не удаляется, а старый сервис снова запускается.
4. Выпустит или переиспользует сертификат Let's Encrypt для `138-16-224-172.sslip.io` и настроит nginx: HTTPS, WebSocket, `/rtc` для LiveKit, загрузки без лимита.
5. Запустит `nova` и `livekit` через systemd и проверит `/health`. Если новая версия не поднялась, автоматически вернёт предыдущую.

После переноса пользователи входят со **старым паролем** по e-mail или имени. Если имя пришлось адаптировать под новый формат (a–z, 0–9, `_`, `.`, без повторов), скрипт выведет список переименований. Сессии не переносятся, поэтому один раз нужно войти заново.

Обновление — та же команда, уже без `--purge-old`. Другие параметры:
- `--admin <логин или email>` — сделать этот аккаунт администратором (`deploy-server.cmd` спрашивает его сам). В конце скрипт перечисляет администраторов;
- `--domain chat.example.com` — свой домен;
- `--email you@example.com` — контакт для Let's Encrypt;
- `--no-migrate` — очистить без переноса данных.

| | |
|---|---|
| Логи | `journalctl -u nova -f`, `journalctl -u livekit -f` |
| Настройки | `/etc/nova/nova.env` (после правки: `systemctl restart nova`). Название и регистрацию удобнее менять в приложении: «Сервер Nova → Обзор» |
| Данные | `/var/lib/nova` (база `nova.db`, `uploads/`) |
| Бэкапы | `/var/lib/nova/backups`: перед каждым обновлением и ежедневно, хранятся 14 дней |
| Порты | 80/443 (tcp), 7881 (tcp), 3478 (udp), 5349 (tcp), 50000–60000 (udp) — для голоса и видео |

> **Безопасность.** Если пароль root куда-то пересылался, смените его (`passwd`). Надёжнее входить по ключу (`ssh-copy-id root@…`) и отключить вход по паролю: `PasswordAuthentication no` в `/etc/ssh/sshd_config`.
>
> В старом Concord был демо-аккаунт `demo@concord.dev` с опубликованным паролем `password123`. Если после переноса у него этот пароль, Nova при запуске отключает аккаунт и снимает с него права. Вернуть его можно в «Сервер Nova → Пользователи» — с новым паролем.

Перенос старой базы можно запустить и вручную: `npm run migrate:concord -- --from <dev.db> --uploads <папка uploads> [--dry-run]`.

## Программа для Windows

```powershell
$env:VITE_API_URL="https://138-16-224-172.sslip.io"; npm run desktop:build
```

Установщик появится в `client/release/`. Без `VITE_API_URL` программа спросит адрес сервера при входе. Для автообновлений укажите свой репозиторий в `client/electron-builder.yml` (`publish`) и выпускайте версии тегом `v1.2.3`: это делает `.github/workflows/desktop.yml`.

> Если запускаете собранную программу из терминала VS Code, сначала выполните `Remove-Item Env:ELECTRON_RUN_AS_NODE`. VS Code задаёт эту переменную, и Electron стартует как обычный Node.

## Android

Нужны JDK 21 (подойдёт встроенный в Android Studio, скрипт найдёт его сам) и Android SDK.

```powershell
$env:VITE_API_URL="https://138-16-224-172.sslip.io"; $env:VITE_API_URL_FALLBACK="http://138.16.224.172"; npm run android
```

APK появится в `client/release/`. Для релизной сборки создайте ключ один раз:

```bash
keytool -genkeypair -v -keystore nova.keystore -alias nova -keyalg RSA -keysize 2048 -validity 10000
```

Задайте `NOVA_KEYSTORE=<путь>` и `NOVA_KEYSTORE_PASSWORD=<пароль>`, затем выполните `npm run android:release`. Подписывайте все версии **одним** ключом, иначе поверх установленной версии не обновиться. В GitHub Actions (`.github/workflows/android.yml`) ключ берётся из секретов `NOVA_KEYSTORE_B64` и `NOVA_KEYSTORE_PASSWORD`.

## CI (GitHub Actions)

- `deploy.yml` — выкладка на сервер при пуше в `main`. Нужны секреты `DEPLOY_HOST` и `DEPLOY_SSH_KEY`.
- `android.yml` — APK в релиз `android`.
- `desktop.yml` — установщик Windows. По тегу `v*` создаётся релиз для автообновления.

Адрес сервера для сборок задаётся переменной репозитория `NOVA_SERVER_URL`.
